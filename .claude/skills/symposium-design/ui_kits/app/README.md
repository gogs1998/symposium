# Symposium app UI kit

Interactive recreation of the Symposium app in the Aegean design language.

Flow: **Roster** (Historical/Creators tabs, figure plaques) → **Figure intro** (portrait plaque, "how this recreation was built" strip with source counts + register labels, openers, Begin) → **Chat** (streamed replies with citations, register chip + nudge menu for creators, disclosure line above the composer, Sources panel over an ink scrim).

Files: `index.html` (router), `RosterScreen.jsx`, `FigureIntroScreen.jsx`, `ChatScreen.jsx`, `data.js` (sample roster + canned grounded replies). All UI composes design-system components from `window.SymposiumDesignSystem_7c9615`.
